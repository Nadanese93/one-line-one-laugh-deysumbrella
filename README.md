A single one-line joke for the Make.fun micro contest "One Line, One Laugh".

> The vending machine ate my dollar, gave me nothing, and still flashed 'thank you' like it did me a favor.

The joke is written by `main.py` (Python 3 standard library only) to `entry.txt` in the output directory, as one line with no trailing newline.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
